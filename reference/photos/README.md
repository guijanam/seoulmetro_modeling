# 실물 사진 (모델링 참고 자료)

서울 지하철 2호선 전동차 실물 사진을 부위별 폴더에 넣어 주세요.
Blender로 모델링할 때 형상·비율·색을 맞추는 기준으로 씁니다.

| 폴더 | 넣을 사진 |
| --- | --- |
| `exterior/` | 차량 전체 외관 (측면 전체, 3/4 각도, 편성 전체) |
| `front/` | 선두부 정면 (전면 유리, 전조등·후미등, 행선 표시기, 스커트, 연결기) |
| `cab/` | 운전실 내부 (운전 제어대, 운전석, 계기류) |
| `doors/` | 객실 출입문 (닫힘·열림, 문 위 안내 표시), 측면 창 |
| `bogie/` | 대차 (차륜, 축상, 공기 스프링, 견인 전동기, 제동 장치) |
| `roof/` | 지붕 (팬터그래프, 냉난방 장치, 지붕 배선) |
| `underfloor/` | 차체 하부 기기 (기기 상자, 공기 탱크, 언더프레임) |
| `interior/` | 객실 내부 (좌석, 교통약자석, 손잡이, 기둥, 천장 조명, LCD) |
| `details/` | 그 밖의 세부 (노선 표지, 차량 번호, 관통문, 연결부 등) |

## 파일 이름

`부위_설명_번호.jpg` 형식을 권장합니다. 예: `front_정면_01.jpg`, `bogie_동력대차_측면_02.jpg`

- 어느 차종(예: 2000호대, 신형 2호선 열차)인지 알면 파일 이름이나 아래 메모에 적어 주세요.
- 정면·측면처럼 **정사영에 가까운 사진**이 치수를 맞추는 데 가장 도움이 됩니다.
- 교육 자료에 함께 실을 사진은 촬영자 본인 사진이거나 사용 허락을 받은 사진만 넣어 주세요.
