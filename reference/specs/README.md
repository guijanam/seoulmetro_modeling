# 열차 제원 문서

서울 지하철 2호선 전동차의 제원을 기록한 문서를 이 폴더에 넣어 주세요.
`blender/scripts/dims.py`의 기준 치수와 부품 설명(`desc_ko`)을 이 문서에 맞춥니다.

## 넣을 문서

- 제원표 (차체 길이·폭·높이, 바닥 높이, 대차 중심 간 거리, 축간 거리, 차륜 지름, 궤간, 출입문 크기·간격 등)
- 편성 구성 (Tc·M·T 배치, 편성 길이, 정원)
- 주요 기기 사양 (견인 전동기, 제어 장치, 제동 장치, 팬터그래프, 냉난방 장치 등)
- 도면·형식도가 있으면 함께

형식은 PDF, 이미지, 엑셀, 텍스트 모두 괜찮습니다.

## 파일 이름

`차종_문서종류.확장자` 형식을 권장합니다. 예: `2000호대_제원표.pdf`, `신형_편성구성.xlsx`
